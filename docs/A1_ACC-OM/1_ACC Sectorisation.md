# ACC Sectorisation

ACC Operations Manual is an Appendix to vFIR Warszawa Operations Manual. This document contains essential information for Polish VACC ACC controllers, as well as APP controllers (coordination procedures). It describes FIR Warszawa sectorisation and positions description, and basic coordination procedures between ACC sectors or ACC and APP controllers.

## ACC Sectorisation

Whole airspace is divided into 10 sectors:

![EPWW SECTORS](/assets/ACC_sectors.jpg)

Each sector is divided vertically into three levels:

- **LOW** - FL95 - FL335
- **MID** - FL335 - FL365
- **HIGH** - FL365 - FL660
